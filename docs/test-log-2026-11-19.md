## 2. 이번 변경 사항

- **디자인 수정**: 흰 바탕(`bg-canvas`) 위 투명 경계 카드 3곳(`ClassCard`, `form.tsx Choice`, `pass/new.tsx` 상품 카드)을 `bg-surface`로 수정. `calendar.tsx`의 미정의 토큰 `bg-brand-300` → `bg-brand-400` 교체. 관리자 오늘 탭 `NotificationBell` 추가, `Switch` 활성 색상 `#0B7A4D` 통일, 하단 탭 활성 아이콘(`focused`) 구분.
- **신규 기능**:
  - 수업 정보 수정 (`app/(admin)/class/edit.tsx`) — 제목·날짜·시각·길이·장소·담당 강사(원장·관리자) 수정, 예약 회원 존재 시 시간 변경 경고
  - 내 프로필(이름·연락처) 및 스튜디오 이름(원장·관리자) 인라인 수정 (`components/ProfileScreen.tsx`)
  - 회원용 수강권 변동 내역 (`app/my-pass/[id].tsx`) 및 지난 수업·출석 이력 (`app/my-history.tsx`)
  - 회원 시간표 강사 필터 (`app/(member)/schedule.tsx`, 강사 2명 이상 시 자동 표시)
  - 공용 미니 달력 모달 (`components/DatePickerModal.tsx`) — 수업 등록·수정, 수강권 시작일, 결제 추가 결제일 적용
- **DB 보안 강화 (`013_harden_class_updates.sql`, 운영 DB 반영 완료)**:
  - `classes` `UPDATE` 권한을 `status·studio_id·created_at` 제외 6개 열로 제한해 `cancel_class()` RPC 우회 차단
  - `guard_class_update()` 트리거에 폐강·시작·과거 시간 수업 변경 차단 가드 추가
- **도구 버그 수정**: `scripts/check-release.mjs` Windows 경로 오류(`new URL().pathname` → `fileURLToPath`) 수정
